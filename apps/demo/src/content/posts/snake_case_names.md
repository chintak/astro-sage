title: "Underscores in file names"
description: "A post whose file name has underscores mid-name: it loads like any other."
pubDatetime: 2026-10-16T09:00:00Z
tags: ["astrosage"]
---

This post is `posts/snake_case_names.md`. Only a **leading** `_` hides a file or folder: `_template/index.md`, `notes/_wip/idea.md` and `_scratch.md` are ignored, in `astro dev` and in the build, whatever `draft` says. Use them for templates and notes you keep next to your posts. An underscore inside a name, as here or in `my_folder/index.md`, changes nothing.
